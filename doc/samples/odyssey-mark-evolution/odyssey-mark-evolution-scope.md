# 《Odyssey 图标是如何形成的》命题与边界

## 核心命题

Odyssey 的图标不是独立于产品理念之外的装饰。它将“长期演进而不失去身份”、Thinking Ownership，以及从不确定性走向可维护结构的过程压缩成了一个视觉符号。

## 页面责任

- 说明分形与递归螺旋为何成为造型起点；
- 说明 V2 至 V4 如何确定最终几何与填充方向；
- 说明 V5 如何把 Thinking Ownership 引入图标；
- 说明 V6 如何将四色组织成可阅读的状态序列；
- 保留真实的试验与取舍，不把设计过程写成从一开始就注定正确的线性故事。

## 页面边界

- 不写成完整品牌规范；
- 不为每个几何比例补造数学论证；
- 不把图标颜色替代为完整的产品状态模型；
- 不把动画制作过程作为本章主线；
- 不声称这一视觉隐喻已经得到用户研究或成熟品牌验证。
