## A Design Project, Not a Finished Product Claim

Odyssey explores how an AI Agent system can remain understandable as it grows: how collaboration is structured, where autonomous judgment is allowed, how knowledge is maintained, and how the same design can move between a visual Canvas and a domain language.

This documentation focuses on **why these decisions were made**. It records the design reasoning, trade-offs, and unresolved questions behind Odyssey rather than presenting the project as a mature product.

The current reading path is complete enough to follow from the problem and design principles into five key decisions, then continue into design evolution and current limitations. Additional concept references and worked examples will be added as the design develops.
